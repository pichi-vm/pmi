# x86-64

This document defines the parts of PMI specific to the x86-64 architecture. An
image is x86-64 when its `PE.FileHeader.Machine` is `0x8664`.

## `cpu:profile`

The x86-64 values of the
[`cpu:profile`](cpu.md#1-new-target-attribute-cpuprofile) target attribute are
the microarchitecture levels of the [System V x86-64 psABI][sysv-abi]:

- `x86-64-v1`, the psABI baseline
- `x86-64-v2`
- `x86-64-v3`
- `x86-64-v4`

Each level is a strict superset of the one below.

## Boot vCPU

The x86-64 boot vCPU state is 32-bit protected mode with paging disabled, at the
reset vector `0xFFFFFFF0`.

| Register                     | Value                                                                                        |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `rip`                        | `0xFFFFFFF0`                                                                                 |
| `rflags`                     | `0x2`                                                                                        |
| `cr0`                        | `0x21` (`PE`, `NE`); `ET` always reads as 1                                                  |
| `cr3`                        | `0`                                                                                          |
| `cr4`                        | `0x40` (`MCE`)                                                                               |
| `efer`                       | `0x901` (`SCE`, `LME`, `NXE`)                                                                |
| `cs`                         | selector `0`, base `0`, limit `0xFFFFFFFF`: 32-bit code, execute/read, non-conforming, DPL 0 |
| `ds`, `es`, `fs`, `gs`, `ss` | selector `0`, base `0`, limit `0xFFFFFFFF`: 32-bit data, read/write, expand-up, DPL 0        |
| `tr`                         | selector `0`, base `0`, limit `0xFFFF`: present, busy 32-bit TSS, DPL 0, byte-granular       |
| `ldtr`                       | selector `0` (no LDT); other fields unspecified                                              |
| `gdtr`                       | base `0`, limit `0xFFFF`                                                                     |
| `idtr`                       | base `0`, limit `0`                                                                          |
| `dr6`, `dr7`                 | `0xFFFF0FF0`, `0x400`                                                                        |
| `IA32_PAT`                   | `0x0007040600070406`                                                                         |
| `xcr0`                       | `0x1`                                                                                        |
| x87 and SSE state            | `FCW` `0x037F`, `MXCSR` `0x1F80`, x87 registers empty, all else `0`                          |

Code and data segments are present, accessed, 4 KiB-granular, and 32-bit (`D/B`
set). `AVL` and `L` are clear on `cs`, `ds`, `es`, `fs`, `gs`, `ss`, and `tr`.
An image entered in this state MUST NOT rely on a field or bit this section
leaves unspecified, or on any register or MSR the table does not list.

## Guest physical address width

A guest learns its guest physical address width from
`CPUID Fn8000_0008_EAX[7:0]` (`PhysAddrSize`).
